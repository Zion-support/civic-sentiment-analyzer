# Civic Sentiment Analyzer

Analyze citizen feedback across 311 hotlines, social media, surveys and public meetings — topic clustering, sentiment trends and policy-impact alerts for public servants.

**Free & open-source (MIT).** Part of the [Zion AI App Network](https://ziontechgroup.com/zion-app-network/) — Batch 79: GovTech & Smart City AI.

## Features
- Multichannel ingestion (311, social, surveys, meeting transcripts)
- Topic clustering and emerging-issue detection
- Sentiment trend dashboards per neighborhood/topic
- Multilingual analysis
- Weekly digest for officials
